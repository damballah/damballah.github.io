Télécharger

WikiFreeCards est gratuit et fonctionne sous Windows. Trois versions sont proposées : choisissez celle qui vous correspond.

  • Les trois versions
  • Laquelle choisir ?
  • Avant de lancer

  • Le plus simple

    Version avec installateur

    Un programme d'installation (.exe) qui installe WikiFreeCards sur votre ordinateur comme un logiciel Windows classique.

    Pour qui : tout le monde, sans connaissance technique.

    Installateur (.exe)

  • Prêt à lancer

    Code source et exécutable

    Le code source Python accompagné d'un fichier .exe compilé à partir de ce code. Décompressez l'archive et lancez l'exécutable, sans avoir Python d'installé.

    Pour qui : ceux qui veulent lancer le logiciel sans installer Python, tout en gardant le code sous la main.

    Version compilée (.zip)

  • Pour bidouiller

    Code source Python

    Le code source complet du logiciel, avec le fichier main.py qui le démarre. Python doit être installé sur votre ordinateur.

    Pour qui : les curieux et les développeurs qui veulent lire, modifier ou forker le projet.

    Le code source (.zip)

Les trois versions sont destinées à Windows et distribuées sous licence MIT. Le code source est aussi disponible sur GitHub.

Laquelle choisir ?

Les trois versions donnent accès au même logiciel. Elles diffèrent seulement par la façon de le lancer.

  • Vous voulez simplement utiliser WikiFreeCards : prenez l'installateur.
  • Vous préférez ne rien installer, ou garder le logiciel dans un dossier de votre choix : prenez la version avec exécutable.
  • Vous voulez lire ou modifier le code, ou vous avez déjà Python : prenez le code source et lancez main.py.

Avant de lancer

Si un exécutable n'est pas signé numériquement, Windows (SmartScreen) peut afficher un avertissement au premier lancement. C'est courant pour les logiciels libres distribués par des particuliers. Dans ce cas, cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
